# 🛒 TechGear

**TechGear** es una tienda virtual de productos tecnológicos desarrollada con **Python y FastAPI**, utilizando **MongoDB** como base de datos.

## 🚀 Tecnologías

* 🐍 Python
* ⚡ FastAPI
* 🍃 MongoDB
* ▲ Vercel
* 🚀 Render
* 🔗 Git & GitHub

## 📋 Características

* Gestión de productos.
* Consulta, creación, actualización y eliminación de productos.
* Conexión con MongoDB.
* API REST con FastAPI.
* Documentación automática con Swagger.

## ⚙️ Instalación

```bash
git clone https://github.com/TU-USUARIO/TechGear.git
cd TechGear
pip install -r requirements.txt
```

Ejecutar el servidor:

```bash
uvicorn app.main:app --reload
```

Documentación:

```text
http://127.0.0.1:8000/docs
```

## ☁️ Despliegue

* **Vercel:** aplicación web.
* **Render:** backend y API FastAPI.
* **MongoDB:** almacenamiento de datos.
